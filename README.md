# FaceID App 🤖
Aplicación web de reconocimiento facial en tiempo real.

🔗 **App en vivo:** https://bucolic-hummingbird-b6f978.netlify.app

## Funciones principales
1. Agregar personas con fotos
2. Reconocimiento facial en tiempo real
3. Eliminar personas registradas
4. Cambiar cámara frontal/trasera
5. Historial de detecciones con fecha y hora
6. Exportar reporte en .txt
7. Estadísticas de detecciones por persona

## Tecnologías
- HTML5, CSS3, JavaScript
- face-api.js (IA para reconocimiento facial)
- LocalStorage
- PWA instalable
- Netlify (hosting)

## Cómo usar
1. Abre la app en el link de arriba
2. Agrega personas con sus fotos
3. Abre la cámara y apunta a un rostro
4. La app lo reconoce automáticamente
